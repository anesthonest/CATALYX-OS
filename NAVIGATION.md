# CATALYX V24 Universal Navigation & Deep-Linking Reference

## 1. Executive Summary
CATALYX V24 establishes a definitive, canonical 9-domain navigation hierarchy. Every module, tool, view, and artifact in the platform has a stable URI route and an active UI entry point. Zero dead ends, orphan views, or placeholder buttons are permitted.

## 3. Deep-Linking URL Specification

CATALYX V24 synchronizes navigation state seamlessly with browser URL search parameters:

```
https://catalyx.enterprise.internal/?domain={domainId}&tab={tabId}&item={itemId}&shareToken={token}
```

### Parameters:
- `domain` *(required for top-level navigation)*: One of the 9 canonical domain IDs (`home`, `work`, `workspace`, `comms`, `commerce`, `intel`, `integrations`, `governance`, `admin`).
- `tab` *(optional)*: Direct tab identifier within the domain.
- `item` *(optional)*: Specific artifact ID (e.g. presentation ID, meeting ID, file ID, demo ID).
- `shareToken` *(optional)*: Cryptographically signed access token generated by `universalShareService`.

## 4. Cryptographic Sharing Schema

Artifact sharing is managed by `src/services/universalShareService.ts`:

```typescript
interface UniversalShareLink {
  id: string;
  token: string;              // cx_v24_[base64url]
  targetType: ArtifactType;   // 'PRESENTATION' | 'MEDIA' | 'DEMO' | 'MEETING' | 'FILE' | 'TASK' | 'WORKSPACE'
  targetId: string;
  targetTitle: string;
  accessLevel: 'VIEWER' | 'COMMENTER' | 'EDITOR';
  passwordProtected: boolean;
  expiresAt: string | null;
  allowedDomains: string[];
  viewCount: number;
  lastAccessedAt: string | null;
  createdBy: string;
  createdAt: string;
  active: boolean;
}
```

### Share Modal Actions:
- **Copy Link**: Copies the full signed URL to the system clipboard with instant UI feedback.
- **Email Share**: Generates a pre-formatted `mailto:` payload containing the secure invitation.
- **QR Code**: Renders a scannable verification matrix for mobile executive review.
- **Revoke**: Immediately marks the link inactive in the local audit register.

## 5. Automated Link Integrity & Audit Verification

The platform includes an automated link and button audit engine in `V24CertificationView.tsx`.
To run the automated suite:
1. Navigate to **Admin & Certification** -> **V24 Certification**.
2. Click **Run All Automated Verifications**.
3. All 12 gates are independently validated, returning latency, pass/fail status, and diagnostic traces.
4. Click **Download V24 Audit Dossier** to export the cryptographically sealed JSON report.
